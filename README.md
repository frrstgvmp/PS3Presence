# PS3 Presence

Русский · [English](README.en.md)

PS3 Presence — приложение для Windows, которое показывает текущую игру с PlayStation 3 в Discord Rich Presence и ведёт локальную статистику игрового времени.

Программа получает статус из PSN: устанавливать что-либо на консоль или использовать CFW/HEN не требуется. Работает с официальной прошивкой, если Sony возвращает сведения о запущенной игре.

Актуальный релиз: [**0.7.1 beta**](https://github.com/frrstgvmp/PS3Presence/releases/tag/v0.7.1-beta). Проект не является официальным продуктом Sony или Discord.

[Скачать для Windows x64 · ZIP](https://github.com/frrstgvmp/PS3Presence/releases/download/v0.7.1-beta/PS3Presence-0.7.1-beta-win64-portable.zip) · [SHA-256](https://github.com/frrstgvmp/PS3Presence/releases/download/v0.7.1-beta/SHA256SUMS.txt)

## Возможности

- Название игры, обложка, время текущей сессии и доступный игровой статус в Discord.
- Главное окно с текущей игрой, PSN-аватаром и состоянием подключения.
- Статистика по играм: накопленное время, число обнаруженных сессий и последний запуск.
- История сессий с датами, длительностью и состоянием; сортировка игр по времени в игре или последнему запуску.
- Работа в системном трее, переподключение Discord и автозапуск Windows.
- Русский и английский интерфейс.
- Event Log с временными метками и локальный кэш обложек.

## Что нужно

- Windows x64. 
- PS3, подключённая к PSN, и доступ к аккаунту, на котором запускаются игры.
- Установленный и запущенный настольный Discord. Одной браузерной версии недостаточно.
- Интернет с доступом к сервисам Sony; для загрузки обложек нужны также доступные серверы изображений.

Статус зависит от данных Sony и обновляется с интервалом опроса. Некоторые игры, демоверсии или сетевые состояния могут не отдавать название либо обложку.

## Быстрый старт

### Готовая программа

1. Открой [релиз 0.7.1 beta](https://github.com/frrstgvmp/PS3Presence/releases/tag/v0.7.1-beta).
2. Скачай `PS3Presence-0.7.1-beta-win64-portable.zip` из **Assets**. Установка и Python не нужны.
3. Распакуй весь архив в постоянную папку и запусти `PS3Presence\PS3Presence.exe`.
4. Оставь папку `_internal` рядом с EXE: без неё программа не запустится.
5. Открой «Настройки» и выполни настройку ниже.

Перед обновлением полностью закрой старую копию программы. Настройки, авторизация и статистика сохраняются в `%LOCALAPPDATA%\PS3Presence`; переносить их в новую папку не нужно. Автозапуск сам на новую папку не переключается.

### Discord

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) и создай приложение.
2. Скопируй **Application ID** и вставь его в поле **Discord Application ID** в настройках PS3 Presence.
3. Оставь настольный Discord открытым под своим аккаунтом.

Нужен именно Application ID — не токен бота, не Client Secret и не пароль Discord. Имя приложения может отображаться в отдельных местах Discord; название текущей игры программа передаёт отдельно.

Поле **Large image asset key** необязательно: это резервный ключ изображения, заранее добавленного в Rich Presence твоего Discord-приложения. Для автоматических обложек его можно оставить пустым.

### PSN / NPSSO

NPSSO — секретный код авторизации PSN. Не публикуй его, полный JSON-ответ Sony или скриншоты с ними.

1. В «Настройки» нажми «Обновить NPSSO».
2. Нажми «Открыть вход Sony» и войди в нужный PSN-аккаунт в обычном браузере.
3. В том же браузере открой [страницу ssocookie](https://ca.account.sony.com/api/v1/ssocookie). При действующей авторизации она должна вернуть JSON с полем `npsso`.
4. Скопируй весь JSON и нажми «Вставить из буфера» в программе.
5. Нажми «Готово», затем «Сохранить» в основных настройках.
6. Запусти игру на PS3 и дождись очередного опроса.

«Готово» подтверждает вставку, но токен сохраняется и применяется только после «Сохранить». «Отмена» или Escape в окне обновления отменяет новую вставку и восстанавливает предыдущее значение.

Проверка буфера пока минимальная: программа принимает поле `npsso` из JSON либо непустой текст. Действительность токена выясняется при подключении к PSN, а не при нажатии «Готово».

Интервал опроса по умолчанию — **30 секунд**, минимальный — **15 секунд**. При истечении авторизации получи новый NPSSO тем же способом.

## Как считается статистика

Статистика собирается локально, пока PS3 Presence запущена, в том числе в трее. Она не загружает старые часы из PSN и не восстанавливает время, когда программа была закрыта.

- Учитывается только наблюдаемое время с подтверждённой активной PS3-игрой.
- Сон компьютера и периоды отсутствующих или устаревших данных PSN не прибавляют время.
- Недоступность Discord сама по себе не мешает учёту.
- Смена игры, подтверждённое отсутствие игры или завершение приложения закрывают сессию.
- Краткий сбой PSN и переподключение Discord не создают новую сессию автоматически.
- «Сессий» — число сессий, обнаруженных приложением, а не исторический счётчик запусков Sony.
- Во вкладке «Сессии» видны последние 100 записей аккаунта; остальные остаются в базе.
- Повторное нажатие на выбранную сортировку меняет порядок по возрастанию/убыванию.

Время начала/окончания — границы наблюдения, а не гарантированное время запуска/выхода на консоли. Длительность может быть меньше промежутка между этими датами. Последний запуск берётся из начала записанной сессии; для старых записей без истории используется доступная дата последнего наблюдения.

Сохранение выполняется примерно каждые 15 секунд и при важных переходах. После аварийного завершения последние несохранённые секунды могут потеряться. Не запускай EXE и Python-версию одновременно: две копии могут учитывать одну игру дважды.

## Обложки

Программа сначала проверяет изображения PSN/PlayStation CDN. Если подходящая картинка недоступна, ищет резервную обложку в [GameTDB](https://www.gametdb.com/PS3/Downloads) по идентификатору или точному нормализованному названию игры. У демоверсии может отображаться обложка полной игры.

Картинки кэшируются локально для интерфейса; в Discord передаётся публичный URL. Если источники недоступны или подходящей обложки нет, появляется геймпад-заглушка. Отсутствие картинки не останавливает передачу статуса и сбор статистики.

## Данные и безопасность

Настройки, авторизация, статистика и кэш находятся в `%LOCALAPPDATA%\PS3Presence`:

- `config.json` — настройки интерфейса и подключения.
- `auth.dat` — авторизация, защищённая Windows DPAPI для текущего пользователя.
- `game_statistics.sqlite3` — игровое время и история сессий.
- `covers` — кэш каталога и обложек.

Файл `observed_game_statuses.json` рядом с программой содержит обнаруженные названия и игровые статусы. При запуске через скрытый Python-лаунчер журналы записываются в `logs`. Такие данные, `.env`, виртуальное окружение и сборки исключены из Git.

Для резервной копии статистики сначала полностью выйди из программы и сохрани базу. Копирование защищённой авторизации другому пользователю Windows не гарантирует её работоспособность.

Пароль PSN программа не запрашивает — вход выполняется на сайте Sony. Для запросов используется неофициальная библиотека [PSNAWP](https://github.com/isFakeAccount/psnawp): её автор предупреждает о риске ограничений аккаунта при чрезмерном использовании API. Проект не гарантирует доступность PSN или отсутствие ограничений со стороны Sony.

## Запуск из исходников

Проверено на **Python 3.12 x64**. Установи Python и Git, затем выполни в PowerShell:

```powershell
git clone https://github.com/frrstgvmp/PS3Presence.git
cd PS3Presence
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\gui.py
```

Необязательная ручная конфигурация: скопируй `.env.example` в `.env` и заполни значения только локально. Сохранённые в приложении параметры имеют приоритет. Не добавляй `.env` в коммит или релиз.

Другие режимы:

```powershell
# Запуск сразу в трее
.\.venv\Scripts\python.exe .\gui.py --tray

# Программная отрисовка без создания 3D-устройства
.\.venv\Scripts\python.exe .\gui.py --software-rendering

# Разовый запрос PSN без подключения к Discord; нужен действующий NPSSO
.\.venv\Scripts\python.exe .\main.py --once
```

## Разработка и сборка

Установи зависимости сборки и запусти офлайн-тесты:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -t .
```

Сборка Windows x64:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Release
.\releases\0.7.1-beta\PS3Presence\PS3Presence.exe --smoke-test
```

Перед упаковкой создай `releases/0.7.1-beta/README.txt` с инструкцией для пользователя и скопируй `LICENSE` в ту же папку, затем:

```powershell
.\.venv\Scripts\python.exe .\tools\package_release.py .\releases\0.7.1-beta
```

Упаковщик проверяет комплектность файлов, отсутствие известных личных данных и целостность ZIP, затем создаёт архив и `SHA256SUMS.txt`. Эти файлы прикрепляются к GitHub Release, а не коммитятся в исходники. Архив одной версии повторно не перезаписывается.

Основные части проекта: `qml/` — интерфейс; `qml_app.py` — контроллер и трей; `bridge.py` — PSN/Discord; `game_statistics.py` и `session_history.py` — учёт времени; `cover_art.py` — обложки; `assets/` — ресурсы; `tests/` — проверки; `tools/`, `hooks/` и `packaging/` — сборка.

## Частые вопросы

**Почему Discord показывает игру с задержкой?**

Программа опрашивает PSN, а не консоль напрямую. Подожди очередного опроса; Sony может обновлять статус с дополнительной задержкой.

**PS3 в сети, но написано «Игра не запущена».**

Это означает, что PSN не вернул активную PS3-игру. Проверь аккаунт на консоли и дождись обновления. Не все игры и состояния возвращают полные данные.

**PS4, PS5 и PS Vita поддерживаются?**

Текущий мост выбирает только активные игры PS3. Поддержка других платформ не реализована.

**Discord не подключается.**

Запусти настольный Discord в том же сеансе Windows, проверь Application ID и используй «Переподключить Discord». Программа не устанавливает и не ремонтирует сам Discord.

**В логе ProxyError, ConnectionError или тайм-аут.**

Наличие интернета не гарантирует доступность Sony и серверов обложек. Проверь VPN/прокси, переменные `HTTP_PROXY` / `HTTPS_PROXY`, DNS и доступ к соответствующим сервисам. Программа не гарантирует работу с любым прокси.

**Антивирус предупреждает о сборке.**

Проверь происхождение архива и его SHA-256; при сомнениях запусти проверенные исходники. Не отключай защиту целиком ради запуска.
